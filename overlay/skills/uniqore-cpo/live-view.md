# Живой взгляд: что проверяющий видит сам, а что остаётся владельцу

Граница проходит не там, где «агент не умеет», а там, где macOS не пускает.
Ниже — что доступно всегда, что открывается одной разовой выдачей прав, и что
не закроется никогда.

## Уровень 1 — без всяких прав, доступно сейчас

Это уже часть порядка приёмки (шаги 2–3 в [`SKILL.md`](./SKILL.md)).

- **Настоящие данные владельца через настоящий код.** Временный `#[test]` или
  `*.test.ts` читает
  `~/Library/Application Support/ai.uniqore.desktopcto/UNIQORE CTO/`
  (`crm.json`, `speech/`, `activity/`) и прогоняет через тот же модуль. Так на
  приёмке «Активности» доказано 448 дозвонов против 829 наборов — числами
  владельца, а не ссылкой на память. Файл после прогона удаляется, данные в
  репозиторий не едут.
- **Экран без шелла — стенд.** `ui/preview/` + `vite.preview.config.ts` в
  `cto-core`: настоящий компонент, настоящий кит, фикстура вместо CRM; экраны с
  Tauri-вызовами поднимаются через `resolve.alias` на заглушки (`invoke`, event,
  opener). Снимок — Browser-панелью; `?print` даёт печатную копию.
  Ловит: вёрстку, кит, тексты, состояния, узкое окно, тёмную тему.
  Не ловит: всё, что считает Rust, и всё нативное.
- **Экспорты — открыть файл, а не поверить кнопке.** PDF читается напрямую,
  XLSX — скриптом. Проверяются числа, бренд-строка, ссылки, имя файла.
- **Порталы на чтение.** Точечные запросы с токеном из `crm.json` в переменной
  процесса. Наружу токен не печатается. amo глушит IP на час после серии —
  один-два запроса на вопрос.
- **Вторая сборка.** Ветка PR собирается в своём воркtree вне репо; в вердикте
  называется дерево и коммит.

## Уровень 2 — настоящее окно приложения. ОТКРЫТ

**Права выданы 2026-09-08, самопроверка пройдена. Что работает и что нет —
проверено пробами в тот же день:**

| Проба | До прав | После |
|---|---|---|
| `screencapture -x` (весь экран) | `could not create image from display` | снимок 2,4 МБ |
| `screencapture -o -x -l<id>` (одно окно) | — | снимок окна 2918×1682, читается глазами |
| `CGWindowListCopyWindowInfo` (swift) | пустой список | `2859  Uniqore  Uniqore  1459x841` |
| System Events: имена окон | `-25211` | `Uniqore` |
| System Events: дерево элементов окна | `-25211` | **пусто по существу** — см. ниже |

**Права выдаются `claude.app` со строчной буквы** — это `com.anthropic.claude-code`
(«Claude Code», живёт в `~/Library/Application Support/Claude/claude-code/<версия>/`),
именно он выполняет команды агента. `Claude.app` из `/Applications` — оболочка
приложения. В списках macOS видны обе строки; нужна обязательно строчная, вторую
можно включить заодно.

### Что реально даёт уровень 2

**Работает — снимок живого окна.** Номер окна берётся из
`CGWindowListCopyWindowInfo` по владельцу `Uniqore`, дальше
`screencapture -o -x -l<номер> /tmp/win.png` и чтение картинки. Окно снимается,
даже когда оно не на переднем плане. Это настоящий экран владельца с живой CRM:
видны сайдбар, дерево воронок, счётчики, заголовки, кнопки, вёрстка — то есть
всё, ради чего уровень и нужен.

**НЕ работает — чтение и клик по имени элемента.** `WKWebView` не отдаёт
System Events содержимое веб-страницы: у окна `AXGroup` плюс три кнопки
светофора, внутри группы — вложенные безымянные `AXGroup`, `entire contents`
возвращает 0. Ни одной подписи, ни одной кнопки интерфейса. Значит:
- клик возможен только по координатам, вычисленным из снимка (хрупко: сдвинулась
  вёрстка — промахнулся);
- текст с экрана читается глазами по картинке, а не строками.

**Правило на этот случай.** Снимок — да, всегда. Клик по координатам — только
когда без него не обойтись, по свежему снимку, и с проверкой результата новым
снимком. В приложении владельца **не кликать вслепую и не трогать идущий
прогон**: перезапуск и клики посреди разбора уже стоили ему готовых разборов.

**Запасной путь на клики и чтение DOM** — отладочный мост в шелле: карточка
T64. Прав macOS не требует, работает и на Windows, читает DOM строками.
`tauri-driver` не годится: на macOS WebDriver для `WKWebView` нет, а
E2E-инфраструктура отвергнута осознанно (2026-08-13).

**Что выдать — один раз, в Системных настройках → Конфиденциальность и
безопасность:**

1. **Запись экрана** → добавить и включить **Claude** (`/Applications/Claude.app`).
2. **Универсальный доступ** → добавить и включить **Claude**.

Права выдаёт владелец: это системный диалог, агент его нажать не может.

**Самопроверка после выдачи** (на новой машине — прогнать снова):

```bash
screencapture -x /tmp/probe.png && echo "снимок экрана: ок" && rm /tmp/probe.png; osascript -e 'tell application "System Events" to tell process "Uniqore" to return name of every window'
```

Обе строки должны ответить без ошибки. Если вторая молчит про окна — окно
приложения свёрнуто в меню-бар, разверни его глобальным хоткеем и повтори.

**Рецепт снимка окна целиком:**

```bash
swift <<'EOF' | head -1
import CoreGraphics
import Foundation
let list = CGWindowListCopyWindowInfo([.optionOnScreenOnly, .excludeDesktopElements], kCGNullWindowID) as? [[String: Any]] ?? []
for w in list where (w[kCGWindowOwnerName as String] as? String ?? "").contains("Uniqore") {
    print(w[kCGWindowNumber as String] as? Int ?? 0)
}
EOF
```

Номер из вывода → `screencapture -o -x -l<номер> /tmp/win.png` → прочитать
картинку. Окно свёрнуто в меню-бар — развернуть глобальным хоткеем; список
окон тогда пуст.

## Уровень 3 — остаётся владельцу навсегда

Это не недоработка агента, а разделение труда.

- **Вкус.** «Некрасиво», «кособоко», «мрачный цвет», «плотность как в Claude» —
  суждение, а не проверка. Правило: спорный визуал показывается 5–7 вариантами
  в реальном размере, выбор за владельцем.
- **Его доступы.** Секреты, коды из почты, вход в кабинеты, подтверждение
  платежей — агенту запрещено вводить.
- **Windows.** Вторая машина; у агента её нет. Проверяется зелёным CI, сторожем
  `drift` и запуском у владельца.
- **Ответ на вопрос «это вообще полезно клиенту».** Приоритет и продуктовая
  развилка — решение владельца.

## Что писать в вердикте

Уровень, на котором смотрел, называется явно: «стенд с фикстурой», «живое окно
приложения», «данные с диска», «не смотрел». Слово «проверено» без указания
уровня — не принимается, это ровно тот случай, за который владелец говорил
«че обманываешь».
