# UNIQORE Desktop delivery test

Это временный тестовый скилл, положенный приложением UNIQORE в `~/.claude/skills/`,
чтобы проверить, видит ли Claude Desktop скиллы из этой папки **без** ручной загрузки
через Customize → Skills.

## Что делать
Если этот навык тебе доступен, ответь ровно: `UNIQORE-DESKTOP-TEST-OK`.
